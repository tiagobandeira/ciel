# Guia de Prompts para Pesquisa Web

Para obter os melhores resultados ao solicitar pesquisas, utilize comandos que incentivem o uso de ferramentas de busca em tempo real. A palavra-chave principal deve ser sempre **'Pesquise'** ou **'Busque'**.

## 🚀 Prompts Rápidos e Eficientes

### 📰 Notícias
- **Geral:** "Pesquise as notícias de hoje no Brasil e no mundo e faça um resumo categorizado."

### 🔍 Fatos e Informações Específicas
- **Eventos:** "Pesquise quem ganhou o prêmio [X] este ano e qual foi a justificativa."
- **Checagem:** "Verifique se a notícia sobre [X] é verdadeira e cite a fonte."

### 🛠️ Tutoriais e Guias
- **Passo a Passo:** "Busque o passo a passo atualizado de como configurar [X] e resuma os pontos principais."

### 📊 Comparativos e Tendências
- **Produtos:** "Pesquise as diferenças entre o produto [A] e [B] com base em reviews recentes."
- **Mercado:** "Quais são as principais tendências de [área/mercado] para 2024? Busque fontes reais."

## 💡 Dicas para Melhores Resultados
1. **Seja Específico:** Quanto mais detalhes sobre o tema, melhor a filtragem.
2. **Defina o Formato:** Peça "resumo categorizado", "lista de tópicos" ou "tabela comparativa".
3. **Peça Fontes:** Solicite que as fontes sejam citadas para garantir a veracidade.
